# Kurd Market - بازاڕی کوردی

## پێداویستییەکان
- PHP 8+
- MySQL / MariaDB
- XAMPP یان Laragon

## چۆنیەتی کارپێکردن
1. فۆڵدەری `kurd_market` بخەرە ناو `htdocs`.
2. phpMyAdmin بکەرەوە و فایلەکەی `database.sql` Import بکە.
3. `config.php` بەپێی ناوی database و password ـی MySQL خۆت ڕێکبخە.
4. لە browser بکەرەوە:
   `http://localhost/kurd_market/`

## بەشی بەڕێوەبەر
- URL: `http://localhost/kurd_market/admin.php`
- Username: `admin`
- Password: `admin123`

> بۆ پاراستنی زیاتر، وشەی نهێنی بەڕێوەبەر بگۆڕە.
